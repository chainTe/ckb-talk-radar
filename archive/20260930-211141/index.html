今日发生了什么

从提供的材料看，今天论坛最集中的动静来自 Spark Program，委员会对多个提案给出催办、Pending、拒绝或未达结项标准等状态更新。[S04, S05, S06, S07, S08, S11]

项目进展方面，Pocket Node v1.8.5 发布，CrowdCell 更新到 v1.2 并与 Vellum 讨论声誉集成，隐私订单簿 milestone.3 完成。[S01, S02, S03, S10, S14]

新讨论里，有人提出无需改合约即可在 CKB 上拥有后量子 owner，并得到一句赞叹回复。[S12, S13]

重点话题

  • Spark Program 今日集中更新：CKB Wallet Behaviour Intelligence 被询问最新进展，zk-Lock for CKB 被认定尚未完全达到结项标准且需开放更多社区参与，Zedify 提案被拒绝，DAO Cycle Alerts 被列为 Pending 并邀请修订，Fiber Weir 被拒绝且提到与现有生态范围重叠，Tranfr 首周更新逾期被催。[S04, S05, S06, S07, S08, S11]
  • Spark Verify 给出可检查的进展：Akane 回复称提供 Week 5 示例，并选择 HNO3Miracle/CKB-UGMP 某个 revision，而不是只给计划。[S09]
  • Pocket Node v1.8.5 发布：应用锁更智能，切换同步设置时钱包保持同步，Nervos DAO 解锁改进，活动条目被清理，解锁后会回到原处。[S01]
  • CrowdCell 与 Vellum 讨论声誉集成：CrowdCell 每个 campaign 已存储创建者 lock，readClaims 可在 campaign 页面展示创建者声誉；回复建议 CrowdCell 拥有 crowdcell.campaign-funded.v1 schema，并在 payout 后发行，还愿意定义 payload 并作为早期合作集成测试；CrowdCell 本身已更新 v1.2 到 testnet，finalization 无信任，campaign cell 在链上维护 running total，每次 pledge 都会更新。[S02, S03, S10]
  • 其他技术进展：后量子所有权笔记称，任何通过 lock hash 授权 owner 并接受任意 lock 的 CKB 合约，今天可无需改合约使用后量子 owner，存储 owner 只需是 Nervos 抗量子 lock script 下的 lock hash，该脚本验证 SLH-DSA (SPHINCS+)；另有隐私订单簿项目宣布 milestone.3 已完成，并给出代码仓库、检验方式和完整设计文档。[S12, S13, S14]

值得继续跟进

  • 跟进 Spark Program 后续：被催的 CKB Wallet Behaviour Intelligence、zk-Lock、Tranfr 是否回复或修订，DAO Cycle Alerts 的 Pending 是否进入修订，以及 Zedify、Fiber Weir 被拒后是否重提。[S04, S05, S06, S07, S08, S11]
  • 跟进 Vellum 与 CrowdCell 的声誉 schema 能否落地为早期合作集成，包括 crowdcell.campaign-funded.v1 的 payload 定义与测试。[S02, S03]
  • 跟进后量子所有权方案是否出现更多讨论或实现，以及 Pocket Node v1.8.5 和隐私订单簿 milestone.3 的社区验证反馈。[S01, S12, S13, S14]
