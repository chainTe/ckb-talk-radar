今日发生了什么

今天 Nervos Talk 的主要动态集中在 Spark Program 提案评审更新和 Fiber 生态推进上。[S02, S05, S06, S09, S14] Spark 这边，Corven IDE 被标记为 Pending 并获邀继续沟通，随后作者称已修订重交；LiquidLane 被拒，Spark Verify 仍 Pending 且被要求补视频演示。[S02, S03, S05, S06] Fiber 相关讨论继续，包括浏览器游戏 FiberSurvivors、FiberLatch 的真实测试网结算更新，以及 FiberNuts 对 LSP 和 UDT/RUSD 支持的追问。[S01, S09, S14] 另外，CKB Off Chain Aba 活动概览下有用户简短好评，CKB Pulse 上线展示 GitHub 公共进展，Kirea Finance 硬化范围也在继续澄清。[S04, S12, S10, S11]

重点话题

  • Spark Program 今天集中更新了多个提案状态。[S02, S05, S06, S07, S08] Corven cloud-native IDE 提案被委员会标记为 Pending，委员会称这不是拒绝，而是邀请继续推进。[S02] 作者随后表示已针对四点修订并重新提交，包括增加 9 个可衡量输出的交付表，每个有具体指标和发布位置。[S03] LiquidLane 的 Fiber 接收容量市场 resubmission 被委员会拒绝。[S05] Spark Verify 仍为 Pending，委员会要求视频演示，因为仅凭书面提案难以准确评估工具用途。[S06] zk-Lock 方面，委员会希望与作者就社区参与的两项优先事项对齐，包括让非开发者参与。[S07] CKB Wallet Behaviour Intelligence 的最新报告已解决大部分问题，只剩功能相关澄清。[S08]
  • Fiber 生态项目与应用继续冒头。[S01, S09, S14] FiberSurvivors 是一个浏览器里的 top-down survivors-like 游戏，像 Vampire Survivors，赚到的 CKB 和买的升级卡都通过 Fiber 支付。[S01] FiberLatch 发布授权后更新，尝试集成 FiberFlow，并进行了真实 Fiber 测试网结算。[S09] FiberNuts 继续追问哪个 Fiber 版本会包含 LSP、是否会有公共测试网 LSP、UDT/RUSD remote-signer 流程是否受支持，以及谁出资。[S14]
  • Kirea Finance 硬化讨论聚焦抵押品安全。[S10, S11] ArthurZhang 指出，从当前代码看，发行方似乎能在不消耗 loan cell 的情况下花费抵押品，从而绕过贷款的释放检查。[S10] SalmanDev 同意这点，并称 Milestone 1 已更新，要求每次抵押品花费都执行贷款验证规则，使抵押品不能以绕过方式移动。[S11]
  • CKB Pulse 发布。[S12] 页面展示 GitHub 上 CKB 的公共工作，按材料所述，过去 7 天有 62 人、58 个项目、627 次更新，每个项目表现为一个 block。[S12]
  • Nervos DAO Treasury pre-RFC 讨论继续。[S13] 针对至少一个 input 必须与 DAO cell 使用相同 lock 的要求，phroi 认为公平，因为该协议不要求重新存入、不使用花哨技术并尽量减少失败点，还称赞了 xjd。[S13] 同一回复还提到，如果这给 RGB++ 造成麻烦。[S13]

值得继续跟进

  • Spark Program 后续要观察 Corven 重新提交后是否通过、Spark Verify 是否补视频、zk-Lock 社区参与如何落地、Wallet Behaviour 功能澄清是否满足委员会，以及 LiquidLane 被拒后的反馈。[S03, S05, S06, S07, S08]
  • Fiber 应用的关键基础设施问题包括 LSP 由哪个版本发布、是否有公共测试网 LSP、FiberNuts 是否必须自营 LSP、UDT/RUSD remote-signer 流程和资金方如何安排，同时观察 FiberLatch 的真实测试网结算和 FiberSurvivors 的 Fiber 支付体验。[S14, S09, S01]
  • Kirea Finance 的 Milestone 1 更新是否真正覆盖“每次抵押品花费都验证贷款规则”，以及 Nervos DAO Treasury 的 lock 要求是否会影响 RGB++ 等生态项目。[S11, S10, S13]
