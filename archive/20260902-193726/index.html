今日发生了什么

过去 24 小时，Nervos Talk 的主要动态集中在 Spark Program 的推进上：委员会批准了两份新提案的资助 [S05, S06]，多个在研项目晒出里程碑进展 [S01, S03, S14]，同时还出现了两个面向 Fiber Network 的新项目 [S13, S15]。此外，上周 Fiber Network 基础设施黑客松的结果也在社区里发酵，有开发者分享了夺冠项目背后的故事 [S15, S16]。整体看，论坛讨论热度不错，属于项目进展密集但无重大突发的一天 [S01, S03, S05, S06, S08, S09, S11, S13, S14, S15]。

重点话题

  • Spark 委员会批准两份新提案资助：Tranfr（CKB 可编程恢复方案）获批 700 美元等值 CKB 资助 [S05]；NNCBN（Nervos 社区 Boot Nodes 网络）获批 1280 美元等值 CKB 资助 [S06]。
  • 两个在研项目宣布完成阶段性目标：zk-Lock for CKB 宣布 M2 交付完成，Lock script 已部署到 Pudge 测试网并跑通首次链上解锁 [S03]；Fiber RGB++ Swap 项目也完成了前三周工作，包括本地 fork 运行、双测试网节点搭建和 SwapAdvertisement 消息设计 [S01]。
  • Fiber 生态迎来两个新面孔：FiberPass 提出为 Fiber Network 构建支付会话层，支持预付费、可撤销、带限额的支付通道 [S13]；CLASP 则宣布其在 Fiber Network 基础设施黑客松中拿下 Wallet & Payment UX 赛道第一名和全场总冠军 [S15, S16]。
  • Corven 新提案遭社区质疑预算不一致：社区成员指出其资金申请明细合计为 24,000 美元，但最终申请金额却写了 15,000 美元，且开发者时薪等细节也存在出入 [S11]。项目方随后道歉，解释称 15,000 美元才是修订后的真实申请额 [S12]。
  • 部分 Spark 项目出现沟通风险：Dular 项目已连续一周联系不上团队，委员会表示希望确认项目方状态，但也暗示将启动相应处理程序 [S09]。另有 CKB Builder Lab 项目因表现获得认可，委员会希望项目方补充更多细节以便社区了解其成果 [S08]。

值得继续跟进

  • Corven 预算修订是否会被社区接受：项目方已承认预算数字不一致并做了修正 [S12]，但社区质疑最早由普通成员提出 [S11]，后续是否还有更多细节问题需要澄清值得关注 [S11, S12]。
  • Dular 项目失联的后续处理：委员会明确表示联系不上项目团队，接下来是项目重启沟通还是被终止，会直接影响 Spark 项目的执行信誉 [S09]。
  • CKB-VM 形式化验证项目的推进：zk-Lock 和 Fiber Swap 之外，CKB-VM Sail Validation Sprint 已完成六周计划中的第 4 周，成功将 CKB-VM 执行路径翻译为 Lean 4 定义（279 个定义、65 个 axiom）[S14]，其验证结论对 CKB 底层安全有意义，可继续留意后续结论 [S14]。
