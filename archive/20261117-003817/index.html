今日发生了什么

按这批帖子看，今天论坛有多条项目更新，整体不算平静 [S03, S06, S11]。CrowdCell 把 keeper 从索引器 API 中拆出，已有社区成员在测试网节点上把第二个 keeper 跑成 systemd 服务 [S03, S04]。Pocket Node for iOS 的 M3 已把同步、发送和交易历史带到可用钱包阶段，并称实现已合并到公开仓库 [S06]。Fiber LSP 则提出把常在线通道运行放到服务器、把通道签名留在钱包，引发社区回应 [S11, S12]。

重点话题

  • CrowdCell 的 keeper 已从索引器 API 拆出，可独立运行，只需测试网密钥和 RPC 配置；随后有社区成员反馈第二个 keeper 已在测试网节点上以 systemd 服务运行 [S03, S04]。
  • Pocket Node for iOS 的 M3 已支持同步、发送和查看交易历史，作者称实现已合并进公开仓库，并提到主网发送能力 [S06]。
  • Fiber LSP 帖子讨论把始终在线的通道运行放到服务器、把通道签名保留在钱包，以缓解移动客户端难以长期在线的问题；有回复称这解决了移动开发者的真实痛点，并提到自己也在做不同方向的 Fiber LSP [S11, S12]。
  • Ward 的验证器从仅 Node 扩展到浏览器，自 ckb-ward 0.5.0 起通过 ckb-vm-js 把 CKB 交易验证器和 CKB-VM 编译到 WebAssembly，并以 ckbVmJs() 作为 lock runner [S09]。
  • MeterNet 宣布 M2 和 M3 已交付，项目是卖按 MB 计费 Wi-Fi 的热点盒，依靠 Fiber 小额支付保持手机在线，目前仅 CKB 测试网 [S08]。

值得继续跟进

  • 量子抗性锁方向出现 ML-DSA 新部署讨论，有回复询问相对既有部署是否需要改很多，后续可看是否形成可复用的第二把 post-quantum lock [S01]。
  • “定时/条件开启信件”类应用有两条线：Message in a Cell 有社区成员称存储成本作为礼物一部分的想法很好，Dead Man's Switch 则尝试“停止签到才打开”的测试网信件；后续可看这些产品如何从概念走向可用流程 [S02, S05]。
  • CrowdCell 的 keeper 拆分后已有测试网运行反馈，后续可看更多社区成员运行 keeper 的实际体验和测试网费用情况 [S03, S04]。
