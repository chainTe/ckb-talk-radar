今日发生了什么

今天论坛的主要热度集中在 Fiber/Cashu 支付与入金路径：FiberNuts 提出资助提案，ckb-on-ramp 发布 testnet demo 并引发讨论 [S03, S05]。同时，CKB DEx 更新 README、UTXOPlay alpha 上线、Tactus 0.02 发文说明，几个项目都在推进 [S01, S11, S13]。钱包与身份侧，Pocket Node 发布 v1.8.6，Vellum 提交 M2 交付报告 [S08, S10]。整体看，今天不是单帖刷屏，而是支付、游戏、钱包和基础设施几条线同时有更新 [S03, S08, S11, S13]。

重点话题

  • FiberNuts 提案请求 6000 美元等值 CKB，计划用 12 周开发验证 Cashu-over-Fiber 结算适配器，并让标准 Cashu mint 发行和赎回 RUSD 计价的 ecash [S03]。有回复称赞文档和 KPI，并提出一对一沟通 [S04]。
  • ckb-on-ramp 发布 testnet demo，目标是让只有 BTC 闪电钱包的新用户不装软件、打开网页就把 BTC 换成 Fiber 通道资产 [S05]。讨论认为若路径跑通，Fiber 可能成为进入 CKB 生态的第一站，并提到 fiber-js WASM、Passkey 和 LSP 商业模式 [S06]。还有回复指出 ckbolt 有类似 demo，并称自己的 ckbolt demo 可能当天或次日上线 [S07]。
  • CKB DEx 进度更新中，LucentLabs 表示已更新 README 来承载相关项目信息，并继续向社区同步 DEx dapp 开发进展 [S01]。
  • UTXOPlay alpha 已上线，当前列出 13 款游戏，作者称仍处早期并希望用户体验后反馈 [S11]。回复中讨论声誉机制应可检查和挑战，并提到可能使用 FiberNuts 的 ecash [S12]。
  • 钱包与开发进展方面，Pocket Node v1.8.6 强调钱包口令保护以及更易理解的备份恢复 [S08]。Vellum 完成第二个 grant milestone，称 M2 把 M1 的 Claim Cell 基础推进到公开 builder record 和真实合作集成 [S10]。Tactus 0.02 聚焦让 rollup 生命周期各环节一致 [S13]。隐私订单簿周报则更新了 proof of buy 的设计和功能开发 [S09]。

值得继续跟进

  • ckb-on-ramp 是 testnet demo [S05]，讨论提到 fiber-js WASM、Passkey 和 LSP 模式 [S06]，同时 ckbolt 也有类似 demo 并可能很快上线 [S07]；后续要看这些网页端入金路径能否稳定跑通并形成可持续模式 [S05, S06, S07]。
  • FiberNuts 已有社区成员称赞文档和 KPI 并希望一对一沟通 [S04]，后续要看 6000 美元等值 CKB、12 周交付和 RUSD 参考应用是否按 KPI 推进 [S03, S04]。
  • Twine 目前使用公共 Nostr relays，作者称这些 relays 受 Nostr 自身限制、用于测试而非生产，并计划在 VPS 上部署自己的 relays [S15]；此前作者也说明 GTBank、Zelle 只是测试台支付方式标签，没有银行集成 [S14]。后续要看测试交易和支付方式说明是否完善 [S14, S15]。
