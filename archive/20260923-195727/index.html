今日发生了什么

今天论坛最集中的动静来自 Spark Program 委员会，它在傍晚连续回复多个项目，涉及 CRT 仍待定、Fiber RGB++ Swap 终止资助、CKB-VM Sail 延期获批、zk-Lock 关闭交付物仍在审查，以及 CKB Wallet Behaviour Intelligence 的下一步建议。[S01, S02, S03, S04, S05] 社区今天还发布了多件新东西：Fiber Test Lab、Zedify、Nervape Artist RGB++ DOB 和 Obscell Web Wallet。[S06, S07, S16, S17] RIVET 帖子收获称赞，也出现对 Phase 1 资助价值的质疑，作者开始逐条回应。[S09, S10, S11, S14] Nervos DAO Treasury 预 RFC 讨论更新了在线投票方案，明确当前不想增加对 ZK 的依赖。[S15]

重点话题

  • Spark Program 委员会集中处理多个项目。[S01, S02, S03, S04, S05] CRT 提案经审查后仍为 Pending，委员会认可其基于 CKB cell model 的可撤销时间锁加密方向是可行交付概念且有真实用例。[S01] Fiber RGB++ Swap 被终止资助，项目由独立开发者 Carl 开发。[S02] CKB-VM Sail Validation Sprint 因开发者身体不适获延期批准，委员会请他康复后告知修订交付日期。[S03] zk-Lock 的最终项目关闭交付物仍在审查中，委员会表示要表达明确立场，但可见材料未展开具体立场。[S04] CKB Wallet Behaviour Intelligence 获委员会感谢，并被建议推进解释/解读工作。[S05]
  • 新工具与项目发布。[S06, S07, S16, S17] Fiber Test Lab 面向 Fiber 支付失败场景，提供本地、可复现的测试。[S06] Zedify 是面向新兴市场商户的 Fiber Network 原生商务平台，从食品、时尚、小工具和车辆卖家起步，结账内置 Fiber Network 支付并支持法币通道。[S07] Obscell Web Wallet 把终端版 CKB 隐私钱包重写为纯前端浏览器版，链上数据与 TUI 版互通。[S17] Nervape Artist RGB++ DOB 提出用实体芯片、Bitcoin UTXO 和 RGB++ 建立艺术家猴子的链上身份与所有权。[S16]
  • RIVET 讨论出现明显分歧。[S09, S10, S11] 有用户称赞它是 CKB 的精彩应用，也有人只简单说“很棒”。[S09, S10] 另有用户质疑区块链重度执行带来的复杂度大于价值，并在支持 Phase 1 资助前提出疑问。[S11] 作者回应时强调 OpenTimestamps 只能证明哈希在某个时间存在，不能备份代码、恢复仓库或提供身份。[S14]
  • CKB Anywhere Card 遭遇资助争议。[S08] 有用户质疑为什么私人事业需要公共项目资助，认为若看好回报应由获利者投资。[S08]
  • Nervos DAO Treasury 投票方案有更新。[S15] chenyukang 表示团队花更多时间探索在线投票方案，最重要原因是不想现在增加对 ZK 的依赖，并贴出当前 CKB 解决方案链接。[S15]

值得继续跟进

  • Spark Program 多个项目的最终状态仍未落定：CRT 仍为 Pending，zk-Lock 关闭交付物仍在审查，CKB-VM Sail 需等开发者康复后给出修订交付日期。[S01, S03, S04]
  • RIVET 是否能推进 Phase 1 资助，以及作者对质疑的完整回应值得观察；当前可见回应只到与 OpenTimestamps 的对比部分。[S11, S14]
  • 新发布的 Fiber 工具/应用和 Nervos DAO Treasury 在线投票方案能否获得社区反馈与推进，值得继续看。[S06, S07, S15]
