今日发生了什么

星火计划（Spark Program）今日密集更新，一笔新资助获批、一个项目被终止，同时多个提案仍在评审中。[S01, S04, S05, S06] 此外，Fiber Network 生态持续活跃，出现了隐私支付工具的新讨论和电动车充电场景的落地探索。[S08, S14]

重点话题

  • Dular 移动支付项目获批 2,000 美元资助：Spark Program Committee 通过了 Dular 提案，全额以 CKB 支付，认可其将 Fiber Network 能力落地到真实移动支付场景，并设有 30 人试点与用户反馈报告的明确交付项。[S01] 项目负责人 duongja 已确认收款地址等后续事项。[S02]
  • CKB Developer Onboarding Guide 资助被正式终止：星火计划委员会经评估后宣布终止对 Milan Matejic 该项目的资助，强调以透明、公正和负责任的态度管理每笔资助。[S04]
  • fiber-payjoin-kit 隐私工具提案引发讨论：ILE_LABS 提出为 Fiber Network 构建协作式隐私支付工具，社区成员关注其与 Lightning 实现的依赖关系及与 Fiber 官方团队的协作方式，项目方回应已配备独立团队并将直接基于 Fiber 原生 API 构建。[S08, S09, S10, S11, S12]
  • Fiber 电动车充电场景推进细节澄清：Sonny 进一步解释其"边充边付"方案——用户只需预先存入 CKB 开通一次通道，后续充电无需重复设置，关闭通道后余额全额返还。[S14, S16]
  • CKB-UGMP 无感铸造基础设施因 demo 链接失效被要求修复：委员会反馈无法访问其 demo 链接（HTTP 400），要求作者提供稳定入口及最小可复现体验步骤。[S06]

值得继续跟进

  • Tiko 项目仍处于 Pending 状态：委员会认为其提案未能清晰说明"具体要做什么、完成标准及委员会如何协助"，需观察提案人 DWSQUIRES 是否会补充关键信息以推动评审。[S05]
  • CKB probe 结项审核悬而未决：xingtianchunyan 告知 clair 项目已进入结项阶段，但审核仍需时间，最终结果待公布。[S03]
  • CKB Kickstarter 众筹平台费率与产品路线：RetricSu 建议将创作者手续费从 3% 上调至 5% 左右，并支持"先 Launchpad、后 BTC"的路线，需关注项目方是否采纳及测试网 MVP 的后续迭代。[S13]
