今日发生了什么

今天 Nervos Talk 最显眼的是两个 DAO 讨论提案达到点赞门槛，并符合进入 Metaforo 投票阶段的条件：RIVET 获得 33 个赞 [S01]，Kaze × CKB UniTour 的肯尼亚第二阶段获得 35 个赞 [S08]。同时，CKBA Dev Rel AMA 发布公告，Hanssen 将参与介绍 [S09]；NNCBN 也发布首周报，称设备已订购但尚未交付 [S02]。开发侧，CKB Community Fund DAO 仪表盘修复了问题，并出现新的实时数据相关 PR [S04, S05]。隐私与命名方向也有互动：Obscell 讨论 Silent Payments，Cellula.id 说明主网合约升级 [S06, S07, S12]。

重点话题

  • RIVET 提案在 7 天讨论窗口获得 33 个赞，符合进入 Metaforo 投票阶段的条件 [S01]。有社区成员对这些点赞提出担忧，发帖人表示已按最终数据审查 [S01]。Kaze × CKB UniTour 的肯尼亚第二阶段获得 35 个赞，也符合进入 Metaforo 投票阶段的条件 [S08]。
  • CKBA Dev Rel AMA 宣布 Hanssen 将参加，他是 CKBA 开发者关系团队负责人，也是 Nervos 生态多年成员 [S09]。社区在帖子下提问：CCC 已发布 Agent Skills，但维护说明称还没有 eval suite；社区想知道 DevRel 的 AI 资源是否会覆盖链上脚本等方向 [S10]。
  • CKB Community Fund DAO 仪表盘方面，JackyLHH 确认用户提交 PR #2 指出的 bug 已修复并部署 [S04]。他解释 AI 工具没有直接合并该 PR，因为其中还包含更广泛的生成数据变更，所以选择更安全路线 [S04]。随后 ebubedev 提交 PR #3，用于代理本地实时数据，并让文档退出浏览器翻译 [S05]。
  • Obscell 隐私钱包讨论中，janx 分享 Silent Payments (BIP352) 已在比特币主网可用，Sparrow 2.5.0 已加入接收支持，包括 air-gapped 硬件钱包签名者 [S06]。LusoCryptoLabs 表示 cellula.id 今天无需协议变更即可工作，.cell 可以把 Obscell stealth address 作为记录发布，并给出 Pudge 示例 [S07]。Cellula.id 还说明合约升级已于昨天 21:00 UTC 上主网，代码哈希不变，name cells 验证方式不变，只有 code cells 移动 [S12]。
  • CKB 节点收入层讨论中，Ayoub_Lesfer 回应称 CrowdCell 上的 release 和 refund 是无需许可的，lock script 会检查资金去向，因此谁提交交易不重要 [S03]。他还把 finalization bot 视为这类机制的好例子，并提到 bot 目前运行情况 [S03]。

值得继续跟进

  • RIVET 的点赞争议和 Metaforo 投票进展值得观察，因为社区成员对点赞提出担忧，发帖人已按最终数据审查 [S01]。
  • CKBA Dev Rel AMA 后续回答值得跟进，尤其是 CCC Agent Skills 没有 eval suite、DevRel 的 AI 资源是否覆盖链上脚本等问题 [S10]。
  • Obscell 与 Cellula.id 的 stealth address 集成是否继续推进，以及 Cellula.id 主网升级后的验证情况，值得观察 [S06, S07, S12]。
