今日发生了什么

从可见帖子看，Nervos Talk 过去一天整体活跃，项目更新、工具发布、提案和讨论同时出现 [S01, S02, S03, S06, S09, S10]。最显眼的是 FiberNuts 重建钱包上线并接入公共测试网 reference mint [S01]，以及 RIVET 公布基于 CKB、IPFS、Arweave 的 GitHub 备份、时间戳和恢复方案，V1 已上测试网 [S02]。此外，Fiber swaps 市场板、RPC/SDK 兼容套件、肯尼亚大学巡讲续期和 CKB 节点收入层等话题也在今天出现 [S03, S06, S09, S10]。

重点话题

  • FiberNuts 在黑客松后的帖子中更新，重建版应用式钱包已上线 fibernuts.xyz，并连接到公共测试网 reference mint mint.fibernuts.xyz [S01]。
  • RIVET 介绍其使用 CKB、IPFS 和 Arweave 备份、时间戳和恢复 GitHub 历史，V1 已在测试网上线并具备 CCC 钱包接入、备份引擎、一键恢复和公开开发者资料 [S02]；讨论中有人把“证明某物在某时间存在”视为同一核心原语，并追问通用版本是否要支持撤销 [S05]。
  • Carl 提议为 Fiber swaps 建立市场板，让 hub 发布可接受的交换、钱包进行发现，补上比特币资产到 CKB 后“找谁换、价格如何”的缺失环节 [S03]。
  • CKB 节点收入讨论继续：帖子指出节点运营有成本、没有 PoS 式奖励流，约 576 个节点在 nodes.ckb.dev 上由利他者、基金会等运营 [S10]；janx 回复建议稍微重新表述，因为这会改变应该问的问题 [S11]；另一个补充角度是让节点通过运行应用实际需要的可选服务赚取费用，而不触碰 secondary issuance [S12]。
  • 其他动态包括 ILE Labs 发布面向节点 RPC 和 SDK 消费者的独立兼容套件初始版本并征集技术反馈 [S06]，Kaze 请求 3,000 美元继续在肯尼亚做三场大学巡讲并现场教学生创建自托管 CKB 钱包 [S09]，Khie 钱包连接器获用户好评 [S07]，Spark 项目更新目标、研究发现、数据和交付 [S08]，Rypto 披露 M1 付款为 1,071,429 CKB [S04]，LucentLabs 发帖请求产品讨论反馈 [S13]。

值得继续跟进

  • RIVET 的 V1 测试网使用反馈，以及通用版本是否需要支持撤销、不可篡改如何用于合约 [S02, S05]。
  • Fiber swaps 市场板是否会形成具体实现，以及它如何衔接 RGB++ 与 Fiber 的资产交换流程 [S03]。
  • CKB 节点收入讨论的走向：协议级奖励、secondary issuance 或可选服务收费哪种获得更多支持，同时观察 Compatibility Kit、Kaze 巡讲和 LucentLabs 产品讨论能否收到实质回复 [S06, S09, S10, S11, S12, S13]。
