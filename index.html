今日发生了什么

从论坛发帖看，今天的主线是 CKB 生态项目更新与 Spark Program 付款、评审同步推进，并非单一话题。[S03, S15, S20, S23] 同时，官网 PR 讨论出现明显分歧：一方认为不更新官网有原因，另一方认为全球官网和海外社媒长期不维护会损害开发者和资金进入。[S08, S09] 此外，Cellula on Fiber 披露了故障场景测试结果并报告 Fiber bug，CKBuilders 成员也发布或介绍了两个新项目。[S21, S01, S02]

重点话题

  • 官网 PR 争论升温：silenceport 称“不更新官网是有原因的”，并称不要帮倒忙 [S08]；Thinker 反驳把停更说成防监管是偷换概念，强调全球官网和海外社媒是面向全球开发者的基础服务 [S09]；psawyerberlin 提出缩小范围、只做时间中性的内容移除清理 [S10]。
  • QuotaCell 更新：作者称已从测试代币推进到可用的 CKB spending Pocket [S03]；回应者认可关闭成本降到 134 CKB 是明显改进 [S04]；随后讨论 keeper 钱包独立且保持小额可限制密钥泄露损害，但需要手动充值 [S04, S05]。
  • Cellula on Fiber 故障测试：团队称跑了支付中途切断、崩溃、重试三个场景且都通过，最终只支付一次、重试被拒绝 [S21]；还发现并报告 Fiber 小 bug（#1724）[S21]；ArthurZhang 表达赞赏 [S22]。
  • Spark Program 拨款与沟通流程：MeterNet 首期 20%（116,140 CKB）已发放 [S20]；CKB-VM Sail Validation Sprint 最终 80%（963,856 CKB）已发放并祝贺完成 [S23]；Corven 确认收到 20% 付款，并接受沟通合并到 Monthly Call、每周日发书面更新 [S17, S18, S19]。
  • 新项目与测试网进展：CKBuilders 成员 Linet_Mugwanja 介绍 CadencePay 和 Message in a Cell 两个项目 [S01, S02]；Noir-CKB 的 private tally 已在 CKB testnet 上线，讨论聚焦真实 ceremony、public inputs 重建防 replay 和链上投票 [S15]。

值得继续跟进

  • 官网 PR 是否按 psawyerberlin 的“只移除、时间中性清理”收窄范围，以及社区对全球官网和社媒维护的分歧能否形成可执行方案。[S09, S10]
  • QuotaCell 的 keeper 钱包安全与运维平衡：小额独立钱包限制泄露损害但带来手动充值负担，capped spending Pocket 能否解决值得看。[S04, S05]
  • Spark Program 中被拒或待推进提案的后续：CellFlow 作者表示理解委员会对缺乏生态需求和架构运营复杂性的担忧 [S06]；Bees Network 被拒后，psawyerberlin 提到可能与自己的项目形成重叠合作 [S16]；Corven 则进入按月沟通和每周书面更新节奏 [S18, S19]。
