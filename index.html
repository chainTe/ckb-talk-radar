今日发生了什么

过去 24 小时的帖子主要围绕资助收尾、提案补充和开发工具发布展开 [S01, S09, S16]。iCKB 宣布资助结项并完成 CCC 迁移，Cellula on Fiber 在被质疑后补充发布 npm 包，Kaze Unitour 确认收到首场款项 [S01, S18, S09, S14]。技术侧有 CKB Cell Framework 发布和 Rust/TypeScript 锁脚本性能对比，社区也继续讨论 Tranfr 的恢复方案 [S16, S17, S04]。

重点话题

  • iCKB 的资助已结项且款项全部花完，但项目继续运行 [S01]；同一作者还宣布 ickb.org 新 DApp、SDK 和 bot 全部切换到 CCC，替代 Lumos 版本 [S18]；此外作者表示因近期 LLM 事件重新检查了 iCKB 合约安全 [S19]。
  • Cellula on Fiber 提案称要给 Fiber 补上普通用户钱包、商户两行代码结账和 AI agent 支付入口 [S06]；有成员指出 npm 上 cellula-mcp 说明写着 agent 尚未发布、公开仓库也没有 pay-with-fiber [S07]；项目方随后称 cellula-agent 0.1.0 与 cellula-mcp 0.4.1 已上 npm 并更新提案 [S09]；也有人表达支持 [S08, S10]。
  • Kaze X CKB Unitour 方面，Machakos 大学 GDGoC 负责人确认 11 月 18—21 日可能举办，但仍待委员会成员私下支持后正式确认 [S11]；后续又提到 Q4 可在不同大学跑完 Unitour、目标 12 月 10 日前 [S12]；zz_tovarishch 称 terrytai 已以个人资助向项目钱包打款 1000 美元等值 833,334 CKB，项目结束后可返还 [S13]，Barsil 确认收到首场 Unitour 款项 [S14]。
  • CKB Cell Framework 由 FoundationLab 发布，定位是让 CKB 合约更易写、易读、易测 [S16]；另一个帖子实测同一锁脚本 Rust 与 TypeScript 版在 58 个场景中接受/拒绝结果一致，但 cycle 成本为 15k 对 15M [S17]。
  • Tranfr 讨论认为原 cheque lock 缺少部分能力，可用 fork lock 增加转账方式 [S03]；提案细化收款人 claim 不再强制把容量退回发送者、6 epoch 延迟改为 per-cell deadline [S04]；有用户表示自己有钱包助记词丢失，认为该方向有帮助 [S05]。

值得继续跟进

  • Spark Program 的 CKB-VM Sail Validation Sprint 结项仍待委员会确认：项目方询问现有交付物是否满足结项、是否需要委员会独立复现，以及尾款流程 [S02]。
  • Cellula on Fiber 需要继续看实际交付与提案是否一致：此前质疑集中在 npm 说明和公开仓库缺失，项目方已补充发布并更新正文 [S07, S09]。
  • Kaze Unitour 的 Q4 多校计划还需与各院校社区伙伴对齐 [S12]；首场款项已收到，而个人资助约定项目结束后返还 [S13, S14]。
