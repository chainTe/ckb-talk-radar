今日发生了什么

今天论坛最集中的动静来自 Spark Program 的集中评审：MeterNet 获批 680 美元（以 CKB 支付）的 grant，但附带补充报告条件 [S04]；同时 Light dApp Kit、CellFlow、TapFiber 和 Spark Verify 等提案被委员会拒绝 [S07, S08, S09, S11]。官网改版讨论也有新进展，有人指出 Journey 页面内容停留在 2024 年 7 月，并把 2023 年硬分叉仍标为进行中或即将推出 [S01, S02]。此外，Fiber Studio v1.1.3 发布、Seedsong 开放 mint、Noir-CKB 测试网上线等产品动态也在今天出现 [S03, S15, S16]。

重点话题

  • Spark Program：MeterNet 提案获 680 USD grant，条件是最终报告要包含现场试点和公开 Web MVP 的用户反馈总结；申请者已接受条件 [S04, S05]。
  • Spark Program 评审结果密集：Light dApp Kit、CellFlow、TapFiber、Spark Verify 均被拒 [S07, S08, S09, S11]；Spark Verify 作者表示理解决定，会继续独立推进 CKB Verify [S12]。
  • 官网更新：讨论提出 Journey 页面最后更新于 2024 年 7 月，建议把“CKB Hardfork 2023”从未完成或即将推出移到成就，并提到 Meepo 硬分叉自 2025 年 7 月 1 日已上主网 [S02]；原帖也指出官网部分内容仍停留在 2023 年 [S01]。
  • Fiber 生态：Fiber Studio v1.1.3 发布，内置节点升级到官方 fnn 0.9.1，并修复通道强制关闭时的链上结算和资金失败问题 [S03]。
  • Seedsong 与 Noir-CKB：Seedsong 委员会反馈此前只有授权地址可 mint，作者回复已开放并提醒清缓存 [S14, S15]；Noir-CKB 的 private tally 已在 CKB 测试网上线，邀请用户试用 [S16]。

值得继续跟进

  • 官网 PR 讨论中的 Journey 页面更新建议是否会被采纳并实际合并，尤其是硬分叉状态和过时内容如何修改 [S01, S02]。
  • Spark Program 本轮被拒的 Light dApp Kit、CellFlow、TapFiber、Spark Verify 后续是否调整重提；Spark Verify 已明确会独立推进 [S07, S08, S09, S11, S12]。
  • MeterNet 获批后的最终报告能否按条件覆盖现场试点和 Web MVP 用户反馈，以及 Fiber Studio 的结算修复在真实使用中的表现 [S04, S05, S03]。
