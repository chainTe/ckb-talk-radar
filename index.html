今日发生了什么

按这批 2026-10-30 的帖子看，今天论坛不算安静，主要动态集中在资助提案审核、付款执行和投票结果上 [S08, S09, S10, S11, S12, S14, S20, S23]。Spark Program 方面，Bees Network 被列为 Pending 后作者补充经济模型与观察真实性章节并重新提交 [S09, S10]；Corven IDE 仍为 pending，作者随后补上预算调整明细 [S11, S12]。DIS 资助方面，Kaze Unitour 的 $3,000 grant 付款时点引发讨论 [S02, S05, S06]，Vellum 因原 Binance 钱包出入金暂停而更换 M2 及后续收款地址 [S14, S18]。技术讨论里，QuotaCell 报告 owner revocation 与 treasury recovery 已在 CKB 上测试 [S01]。

重点话题

  • Spark Program 今天有多条审核与修订动态 [S09, S10, S11, S12, S13, S19]。Bees Network 被委员会列为 Pending 并邀请修订 [S09]，作者随后补充 §6 经济模型与 §7 观察真实性并重新提交 [S10]。Corven IDE 仍为 pending，委员会指出预算调整不清楚 [S11]，作者随后更新了逐项预算调整 [S12]。Light dApp Kit 记录了 JoyID testnet 在无头 CI 测试中的接入阻塞，目标是覆盖 JoyID testnet connect flow 的自动化回归测试 [S13]。zk-Lock 话题下委员会成员问候作者病情并表达期待更新 [S19]。
  • Kaze X CKB Unitour 的 $3,000 grant 讨论集中在“是否已获批”和付款安排上 [S02, S03]。有评论认为提案摘要已包含资金用途拆解 [S03, S04]。也有评论建议先支付 $1,000、后续再付余款 [S05, S07]。另有评论指出原提案没有明确资金释放时点 [S06]。
  • Vellum 的作者请求将 M2 付款改到新钱包，因为原提案附带的 Binance 钱包出入金暂停 [S14]。委员会成员同意更换并请作者提供新钱包地址 [S15]，作者随后给出新地址 [S16]。作者确认后续所有里程碑付款都使用新地址 [S17, S18]。
  • Kirea Finance 投票结果显示 Not Passed，approval 为 21.08%/51%，总投票权重为 155,002,245/13,982,642 CKB [S23]。Rypto 的 M2 付款 $1,125 已按 0.00138 折算为 815,218 CKB，并附上交易链接 [S20]。
  • QuotaCell 本周测试了 owner revocation 和 treasury recovery [S01]。Fiber LSP 讨论涉及支付延迟，建议用 WebSocket 订阅接收签名请求以降低每笔支付延迟 [S21]，同时提醒控制 CPU 配置和 store_sync_writes 等测试变量 [S22]。

值得继续跟进

  • Spark Program 的 Bees Network 修订版和 Corven 预算明细能否让委员会结束 pending 状态，值得看后续审核 [S10, S12]；Light dApp Kit 的 JoyID testnet CI 阻塞是否解决也值得跟进 [S13]。
  • Kaze Unitour 的 $3,000 grant 是否获批，以及是否采用先付 $1,000 的折中付款安排，需要继续观察 [S02, S05, S07]。
  • Vellum 后续 milestone 是否确实打到新地址，需要看委员会打款记录 [S17, S18]；Kirea Finance 未通过后的下一步在可见材料中没有说明 [S23]。
